# บอทแบบนักแข่ง: ใช้ CP / Stratagem / Reserves อย่างไร

เอกสารนี้สรุปหลักคิดที่นักแข่ง 40K ใช้ แล้วแปลงเป็นกติกาที่บอทใช้จริง (โค้ดอยู่ใน `src/ai/botStrats.ts`, `bot.ts`, `botMove.ts`)
วัดผลด้วย arena: `ARENA=1 ARENA_GAMES=4 npx vitest run src/engine/arena.test.ts` (บอทปัจจุบันเล่นกับ baseline ที่แช่แข็งไว้)

## 1. CP คือทรัพยากรที่ต้องใช้ให้หมด
- **CP ที่เหลือตอนจบเกม = เสียเปล่า** นักแข่งวางแผนใช้ CP ทุกเทิร์น
- ค่าของ 1 CP ไม่คงที่: ถ้า CP เหลือเยอะเทียบกับรอบที่เหลือ แต่ละ CP ก็ถูกลง
  - บอทใช้ `cpWorth()`: CP ต่อรอบที่เหลือ < 1 → 1 CP ≈ 14 แต้มความเสียหาย, < 2 → 10, มากกว่านั้น → 7, รอบ 5 ลดอีก 40%
  - ทุก stratagem (Command Re-roll, Smokescreen, Heroic Intervention, Counteroffensive, Explosives, Crushing Impact,
    stratagem ของ detachment ทั้งรุกและรับ) เทียบ "แต้มที่ได้/กันได้" กับ `cpWorth × ราคา`
- เก็บ 1 CP ไว้ Command Re-roll (ทอยชาร์จ/save สำคัญ) จนถึงรอบสุดท้าย

## 2. Command Re-roll ใช้กับลูกที่เปลี่ยนผล
- ทอยชาร์จที่ขาดนิดเดียว, save ของหน่วยแพง, hit/wound ที่ลูกเดียวฆ่าโมเดลแพงได้
- จำนวน attack แบบสุ่มที่ออกต่ำ (D6 ได้ 1), damage ที่ออกต่ำใส่ยานพาหนะ, hazard ที่ตก
- คิดเป็นค่าคาดหวัง: (โอกาสสำเร็จของลูกใหม่) × (แต้มที่ได้ถ้าสำเร็จ) ≥ ค่าของ CP

## 3. Reserves และ Rapid Ingress
- **ทำไมต้องเก็บไว้ใน reserves**: ไม่โดนยิงรอบแรก, ลงในจุดที่ศัตรูทิ้งไว้, บังคับให้ศัตรูต้องกันพื้นที่ (screen)
- **Rapid Ingress (ลงตอนจบ Movement ของศัตรู)** คุ้มเมื่อ:
  1. หน่วยประชิด: ลงแล้วตาเราเดิน + ชาร์จได้เลย (ระยะชาร์จจริงยาวกว่าลงตาตัวเองมาก)
  2. ได้แย่ง/ขวาง objective ที่ศัตรูถือไว้บาง ๆ หรือว่าง ในตาเรา
  3. หน่วยยิงที่ลงแล้วตาเรามีเป้าในระยะ
  4. ตั้งแต่รอบ 3 ไป หน่วยที่ยังอยู่ใน reserves = แต้มที่ไม่ได้ทำอะไร
- บอทให้คะแนนจุดลงแต่ละจุด (`ingressWorth`) แล้วจ่าย 1 CP เมื่อคะแนน ≥ ค่าของ CP
- หน่วยใหญ่ (20 ตัว) ที่ลงจากขอบสนามต้องอยู่ในระยะ 6" จากขอบ: บอทจัดแถวเหลื่อมกันชิดขอบ (`wideFormation`)

## 4. ตาของศัตรู (reactive)
- **Smokescreen**: หน่วย SMOKE ที่กำลังจะโดนยิงหนักที่สุด
- **Heroic Intervention**: ศัตรูชาร์จเข้ามาใกล้หน่วยประชิดของเรา และการต่อสู้คุ้ม
- **Counteroffensive (2CP)**: ให้หน่วยประชิดที่แรงที่สุดตีก่อน เมื่อฆ่าได้คุ้ม 2 CP
- **Fire Overwatch**: ยิงใส่หน่วยที่กำลังจะชาร์จ/ลงสนามใกล้ ๆ
- **Insane Bravery**: หน่วยที่ยืน objective หรือหน่วยแพง และโอกาสตก battle-shock สูง

## 5. ตาของเรา
- **Stratagem ของ detachment ฝั่งรุก**: ลองใส่ผลของแต่ละอันกับหน่วยที่กำลังยิง/ตี วัดความเสียหายที่เพิ่ม เลือกอันที่คุ้มที่สุด
- **Explosives / Grenades**: ใส่หน่วยที่มีโมเดลแพง save ดี (MW ข้าม save)
- **Epic Challenge**: เมื่อศัตรูมี CHARACTER ที่ฆ่าได้คุ้ม

## 6. ที่ยังทำต่อได้ (แผน)
- วางแผน CP ล่วงหน้าทั้งเทิร์น (ตอนนี้ตัดสินทีละจุด)
- Screen: วางหน่วยถูก ๆ กันพื้นที่ deep strike ของศัตรู (ห้ามลงภายใน 9")
- ลง reserves ครึ่งหนึ่งของกองทัพตามจุดประสงค์ (ตอนนี้ลงเฉพาะหน่วย Deep Strike)
- เลือก secondary ให้เข้ากับกองทัพ (fixed vs tactical) และวางแผนให้ทำได้
